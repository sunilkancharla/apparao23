## Runtime design and limits

The user accepts missing filesystem confinement only for this synthetic trial. Local adapter/gateway checks and a recorded disconnection attestation replace the failed AppContainer boundary operationally; neither constitutes exhaustive egress enforcement. Network state is rechecked around/between workers. No external probes, Windows/profile/permission changes, real documents, cloud fallback or Ollama call.

Workers use explicit original base Python with `-I -S -B`, then the project-only package directory, avoiding redirector children and global site packages. Each direct worker has a verified one-process Job and up to 1.5-GiB private-commit cap; safe memory-control workers use 64 MiB. UV gets bounded discovery descendants and 512-MiB per-process cap. Controller private commit is monitored at polls against 512 MiB; it does not have that inherited kernel cap, which would also limit the 1.5-GiB nested workers. Report monitored/sampled values honestly. Native Job behavior is untested in the manual terminal until the offline run.

The runner measures observed private commit and working-set peaks, not an exact continuous private-memory maximum. RapidOCR's constructor is lazy: model/session loading is included in its recorded OCR time, and this is labelled rather than misreported as pure recognition latency. Early worker startup, version/key/provider mismatch, missing assets, unsafe paths, unexpected process counts, active gateway, output/disk/deadline failure or cleanup uncertainty stops the package. Additional disk checks include positive growth of project package/cache roots plus new fixtures/receipts. No whole-machine filesystem audit or complete security guarantee.

Fixture code specifies three synthetic PDFs, ten original/derived rasters, local gold review, readable/degraded case separation, native/scanned page checks and local raw-versus-sanitized summaries. It has not materialized any file. Negative backend-unavailable is an injected exception sentinel, not deletion of a real DLL; corrupted image controls exercise decoding only during offline execution. No measured CER/WER, real box/provenance fidelity, OCR version match or CPU compatibility is claimed from fake tests.
