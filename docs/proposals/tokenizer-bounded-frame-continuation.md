## The output contract

An **excerpt frame** is an ASCII JSON object with an ID, source identity, location/continuation information and selected text. Its limit is **1,536 bytes after JSON escaping**, including all frame metadata. Do not size only the original Unicode text. A **reader response** contains at most three frames and is at most **6,144 ASCII bytes in its final serialized form**, including envelope, separators, metadata and newline. Serialize once, measure once, then write those exact admitted bytes; no preceding headings or later uncounted prints.

Prepare frames as ignored JSON data, with a manifest of exact sizes/digests. A reader accepts only manifest-listed group IDs, verifies identity, strict ASCII/JSON and the whole-response bound, then emits at most one response. Do not pass an arbitrary path or print a whole code/map dictionary. Use a host output-token allowance of 8,192 for these small reader responses, plus the unchanged 32 KiB complete-capture guard.
